## 待核对项

- Grok Image I2I：Kie schema 写 `image_urls.maxItems=5`，字段说明写“up to 1”，建议产品侧保守按 1 张，必要时向 Kie 确认。
- Kling 2.5 Turbo Pro I2V：Kie 页面标题是 v2.5，但 OpenAPI `model_enum` 返回 `kling/v2-1-master-image-to-video`，疑似 Kie 文档枚举笔误；实际提交仍应沿用当前 Kie 支持的 `kling/v2-5-turbo-image-to-video-pro` 或用测试任务确认。
- Veo 3.1：Kie 官方 enum 使用 `veo3` 表示 Quality，Fast/Lite 为 `veo3_fast` / `veo3_lite`；不要把产品名 `Quality` 直接当 API model，除非 Kie 后台另有私有 alias。
- Seedance 2 系列：Kie schema 的 duration 写 4-15s；当前前端若只开放 5/10/15s，需要决定是跟 Kie 放开连续时长，还是继续做产品层简化。
- Wan 2.7 Image Pro：4K 仅 text-to-image Standard Mode；图生图 4K 不应直接开放，除非 Kie 文档更新。
